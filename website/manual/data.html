备份与同步

Kkindle 提供两种数据保护方式：本地 .kkindle 备份适合手动迁移和离线保存；S3/WebDAV 云端同步适合多台电脑之间持续同步。两者用途不同，建议在首次配置云同步前先导出一份本地备份。

导出本地备份

  1. 打开“设置 → 数据与同步 → 备份与恢复”。
  2. 点击“导出备份”，在文件选择窗口中指定保存位置。
  3. 等待导出完成，确认 .kkindle 文件出现在目标位置，再将它复制到外置磁盘或其他安全位置。

备份包包含书籍文件、封面、书库信息、阅读记录和回收站内容。它可以复制到另一台设备，但账号密码、API Key、同步加密密钥不会放入备份包。S3/WebDAV 的敏感凭据需要从对应同步设置中单独导出。

可以开启“启动时自动备份（每日）”，并设置保留数量。Kkindle 在距离上次备份超过约 20 小时时生成新备份；定期检查备份文件所在磁盘是否仍有足够空间。

导入备份或迁移到新电脑

  1. 在旧电脑先导出最新 .kkindle 文件，并复制到新电脑。
  2. 在新电脑安装并启动 Kkindle，打开“设置 → 数据与同步 → 备份与恢复”。
  3. 点击“导入备份”，选择 .kkindle 文件。
  4. 先关闭所有打开的阅读器，再确认导入。
  5. 等校验和导入完成后，回到电脑书库检查书目、格式和阅读进度。

导入会覆盖当前书库。若目标电脑已有书籍或阅读记录，先从目标电脑另导出一份备份。导入后需重新配置 API Key、邮箱密码和云端加密密钥。

配置 WebDAV

  1. 打开“设置 → 数据与同步 → 云端同步”，选择 WebDAV。
  2. 服务地址填写服务器上已经存在的目录，例如 https://dav.example.com/dav/；需要认证时填写用户名和密码/应用密码。
  3. 如果服务商要求自定义同步子目录，在高级选项中设置；默认目录名为 kkindle。
  4. 点击“保存设置”，再点击“测试连接”。测试会验证读写能力并清理测试文件。
  5. 测试成功后点击“立即同步”。按钮会使用已经保存的配置；仅测试连接不会保存表单内容。

配置 S3 或兼容服务

  1. 在云端同步页选择 S3。
  2. 填写 Bucket、区域和 Access Key/Secret Key；使用 MinIO、Cloudflare R2 或其他兼容服务时，按服务商要求填写 Endpoint 和 Path-style 选项。
  3. 如需加密，设置本地加密密钥；在其他电脑上输入完全相同的密钥。
  4. 点击“保存设置”，运行连接测试，再点击“立即同步”。

访问密钥和本地加密密钥不包含在书库备份中。需要迁移连接信息时，使用 S3 设置中的独立连接参数导出，并把导出文件当作含有敏感凭据的文件保管。

多台设备保持一致

所有设备应选择相同的同步方式，并使用相同的 WebDAV 子目录或 S3 对象前缀。启用加密时，所有设备还必须使用相同密钥。忘记密钥后，已加密的云端数据无法恢复。 更换密钥或启停加密时，先改用新的同步子目录/对象前缀，再在其他设备配置同一套新参数。

可设置启动时、退出时或定时同步。关闭“同步时下载完整书籍”后，只同步书籍元数据和封面；在另一台电脑打开书籍或点击下载图标时再获取书籍文件。书卡同步状态图标可提示未同步、已同步或待下载状态。
