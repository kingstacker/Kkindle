BEFORE YOU START

下载前，先知道这几件事。

Kkindle 支持哪些文件格式？

可以导入和阅读 EPUB、PDF、MOBI 与 AZW3。格式转换依赖用户自行安装的 Calibre。

我的书和 API Key 会上传吗？

书籍、封面、阅读记录默认保存在本机。AI 请求只发送相关片段，API Key 使用系统安全存储。

macOS 下载后如何打开？

请按照仓库中的 macOS 安装说明操作。发布包是否经过公证，以对应版本的发布说明为准。

在哪里反馈问题或查看更新？

可以在 GitHub 仓库提交 Issue，或者查看 Releases 和更新日志。
