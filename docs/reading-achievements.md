# 阅读勋章

入口：阅读资料 → 阅读数据。统计卡片下方显示最近获得的勋章和下一枚目标；“查看全部”展开 12 枚勋章，支持全部、已获得和未获得筛选。点击勋章查看条件、进度和获得时间。获得提示在返回书库或查看阅读数据时显示，可以关闭，不中断阅读。

| 系列 | 门槛 |
| --- | --- |
| 阅读时光 | 累计 1、10、100 小时 |
| 阅读足迹 | 累计 7、30、100 天 |
| 阅读习惯 | 连续 3、7、30 天 |
| 完读旅程 | 标记已读 1、5、20 本 |

## 统计规则

- 沿用阅读器前台可见时的计时。时长不是注意力或阅读质量的测量。
- 一天合计满 300 秒计为阅读一天，多次阅读、不同书籍可累加。当天尚未达到门槛时，昨天延续下来的连续记录保留至当天结束。
- 日图仍显示近 14 天；连续天数和历史最长连续天数使用完整历史。未获得的连续勋章展示本次连续进度，已获得的勋章不会因中断而收回。
- 新记录同时保存 UTC 日期和记录时设备的本地日期，跨日保存按时间分段；同步后保持记录时的日期，不随接收设备时区重新归档。此版本没有手动选择统计时区的设置。
- 旧数据只有 UTC 日汇总的部分保留原日期，并在界面注明。旧日汇总减去已有本地日期来源的部分，避免新旧客户端同步时重复计时。
- 完读以书库中明确标记“已读”为准，达到末页或拖动进度条不会自动算作完读。记录首次确认时间；同一本书的不同格式、相同内容的重复导入合并计数。回翻、改回待读或移出书库不撤销已经记录的完成。
- 启用时按可靠历史补发，历史勋章不显示推测的达成时间，也不逐枚弹出通知。之后实时达成的勋章正常提示。

## 持久化与同步

规则定义在 `ReadingAchievementRules`，获得记录与统计数据分离。SQLite 增加 `ReaderAchievementAwards`、`ReaderCompletions`、`ReaderAchievementMetadata` 和 `ReaderLocalDayCounters`，初始化使用幂等建表和迁移。完读记录随书库状态事务保存，获得记录随阅读计时事务保存。

S3 与 WebDAV 使用同一套快照字段：勋章与完读记录取并集，获得时间保留最早值，已提示状态合并；每日计数按设备及原始文件身份取最大值，之后累加各设备数据。远端清理必须确认目标快照完整覆盖这些记录。

默认重置统计保留勋章及完读记录；勾选“同时清除”后，两者也清空。勋章重置使用独立的代次标记，旧的离线快照不能恢复被清除的勋章；已读状态仍保留在书库里，不会在下次启动时重新补发。勋章清除后的快照使用版本 4，旧客户端需要升级后同步。

本地备份随数据库保存以上记录。获得提示开关是本机设置。

## 验证

`ReadingAchievementTests.cs` 覆盖 300 秒边界、超过 14 天的连续历史、本地与 UTC 跨日、历史日期兼容、重启保留、回翻与删除、格式和重复导入去重、离线时长合并、提示状态、重置代次以及重新获得。

UI 测试覆盖中文窄窗口与英文深色主题、勋章墙筛选、详情、提示开关持久化和重置确认。设置 `KKINDLE_SETTINGS_ARTIFACTS` 可保存界面截图。
