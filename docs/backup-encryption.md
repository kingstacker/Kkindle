# Kkindle 加密数据备份

导出、导入完整数据时使用 `.kkindle` 文件。书库数据库、书籍、封面、回收站、批注、书签和阅读记录全部在加密封装内，文件外不包含书名或数据清单。同步密钥、账号会话、API Key 和连接密码不纳入备份。

## 设置和恢复

1. 在同步设置中设置并保存“同步密钥”。不需要先开启云同步，也不需要服务器保管密钥。
2. 导出数据时使用该密钥生成加密 `.kkindle` 文件。未设置密钥时，应用会在打开文件选择界面之前提示设置。
3. 导入时也先检查本机密钥。换设备或重装后，请设置导出时使用的原密钥，再选择备份文件。
4. 应用验证整份文件后才开始替换书库。错误密钥、损坏、截断或多余数据会拒绝导入；成功恢复后须完全关闭并重新打开应用。

**密钥由用户自行牢记和保管，永不上传服务器，也不包含在备份中。遗忘后，服务器和开发者都无法恢复已有加密数据。账号密码重置或设置新密钥不能解密旧数据。** 同一云目录中的设备也必须使用相同密钥；换密钥应使用新的同步目录，避免混用。

中国区和国际区分别保存本地密钥配置。恢复只使用当前区域已经设置的密钥，备份不会替用户切换区域或恢复账号登录状态。

旧版明文 ZIP 结构的 `.kkindle` 文件不再接受导入。仍有旧版数据时，先在原设备打开书库，用支持加密备份的版本设置密钥并重新导出。

## 文件格式

格式标识为 `KKINDLE-BACKUP2`，采用随机 16 字节盐、PBKDF2-SHA256（600,000 次）派生 AES-256 密钥。数据按最多 1 MiB 的块使用 AES-GCM 加密，每块带随机 12 字节 nonce 和 16 字节认证标签。认证附加数据绑定文件头、块序号与块长度，末尾有经过认证的结束记录，拒绝截断、块重排和尾随数据。相同数据和密钥重复导出也会生成不同密文。

导出直接写入加密临时文件，完成后原子替换目标文件。导入会在本机应用私有的临时目录中解密、验证并暂存，完成或失败后清理；不向服务器发送备份、密钥或解密内容。设备上的原始书库仍由应用本地数据目录管理。
