# 设置与词典

打开主窗口左下角“设置”，左侧类别按功能分组。修改后留意页面上的保存按钮；云端同步页面中的“测试连接”不会替代“保存设置”。

## 设置类别速查

- **通用**：界面语言、主界面主题和启动行为。
- **书库与导入**：默认打开格式、Calibre/`ebook-convert` 路径和书库显示设置。
- **阅读与辅助**：全局排版、阅读主题、AI 服务、本地词典查询和听书。
- **设备与传输**：Kindle 连接、Send to Kindle、邮箱发送及设备工具。
- **数据与同步**：本地备份与恢复、回收站、自动备份、S3 和 WebDAV。
- **高级与集成**：MCP 等可选集成；不使用外部 AI 客户端时可以不配置。
- **关于与更新**：版本信息、检查更新、使用手册、诊断和日志导出。

## 安装本地词典

1. 打开左侧“设备管理 → 字典管理”。
2. 点击导入，选择本地词典文件。
3. 等待索引完成，再在阅读器选中词语查询。

支持 MDX、UTF-8 文本以及若干 Kindle 词典格式。导入 Kindle 词典需要 Calibre；受 DRM 保护的词典不能导入。网络百科查询用于查找准确条目，常规词义仍建议使用本地词典。

## 主题和排版

主界面主题在“通用”中设置，影响书库、侧栏和设置页面。阅读器主题和排版可在“阅读与辅助”调整；排版设置包括字号、行距、正文宽度、字体及竖排，并作为全局设置应用到书籍。

## 诊断与日志

在“关于与更新”中的诊断区域检查数据目录可写状态、PDF 解析器、WebView、Calibre、TTS 和 Kindle 服务。先按诊断结果修复未就绪项目，再重试对应功能。

向项目反馈问题时，在同一类别导出软件日志，并附上 Kkindle 版本、操作系统和可复现步骤。日志包不含邮箱密码、API Key 或书籍文件；发送前仍要检查你手动添加的截图和附件。
