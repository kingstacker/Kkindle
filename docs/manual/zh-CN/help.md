# 常见问题

## 导入后找不到书

先确认左侧选中的是“电脑书库”，不是“设备书库”。清除搜索词和格式筛选，再按书名、作者搜索。导入同名文件时若选择“跳过”，本次文件不会加入书库；也可以检查书籍详情中是否作为另一种格式添加。

## TXT 章节目录不正确

TXT 导入会识别常见编码、章节标题和分卷标题。若目录未正确生成，先用文本编辑器确认章节标题单独成行，并检查编号、标点和卷标题是否统一。重新导入前可删除错误的导入记录；原始 TXT 文件不会因导入而被改写。

## 书籍打不开或封面空白

确认文件没有 DRM，且文件本身没有损坏。AZW3 阅读仅支持无 DRM 文件。封面读取失败时，可以在书籍详情里重新匹配或导入封面。格式转换需要安装 Calibre，并在“设置 → 书库与导入”确认 `ebook-convert` 可用。

## Kindle 没有出现在设备书库

1. 解锁 Kindle，并在设备上选择 USB 文件传输模式。
2. 确认数据线支持传输数据，不只是充电；换一个 USB 端口再试。
3. 暂时只连接一台阅读设备，再等待 Kkindle 检测。
4. 查看“设置 → 关于与更新”里的 Kindle 服务诊断，以及 Windows 是否能看到设备存储。

设备识别后再进入“设备书库”。如果系统和 Kkindle 都看不到设备，先解决 USB/MTP 连接问题。

## 传书后 Kindle 里暂时看不到

先确认 Kkindle 提示传输完成，再安全弹出设备。回到 Kindle 主屏刷新书库；部分设备需要重新启动或等待索引完成。若发送格式不受设备支持，先用 Calibre 转换为兼容格式。

## Send to Kindle 和 USB 传输有什么区别

USB 传输需要设备物理连接，文件直接写入设备；Send to Kindle 走 Amazon 在线服务，发送后还要等待 Kindle 联网同步。确认在线发送账号和目标设备无误后再发送。

## 扫描版 PDF 搜不到文字

扫描版 PDF 是页面图像，Kkindle 当前不提供 OCR。可以缩放阅读、旋转页面和添加页面笔记；要搜索文字，先用外部 OCR 工具生成带文本层的 PDF。

## AI 连接失败

核对服务商的 API 地址、API Key、模型名称和账号权限，再检查网络功能是否开启。对 OpenAI 兼容接口，接口地址和路径按服务商说明填写；不要把 API Key 发到公开反馈中。

## 云同步只同步了封面，没有书籍文件

检查“同步时下载完整书籍”是否关闭。关闭时只同步元数据和封面；在另一台电脑打开书籍或点击下载图标后才拉取文件。

## 改了同步设置，立即同步仍使用旧配置

先点击“保存设置”，再点击“立即同步”。“测试连接”只检查当前填写的地址和凭据，不会保存设置。

## 如何恢复误删书籍

打开“设置 → 数据与同步 → 回收站”，选中书籍或格式并恢复。若已永久清理，只能从较早的 `.kkindle` 备份恢复；恢复备份会覆盖当前书库。

## 仍然无法解决

在“设置 → 关于与更新”查看诊断并导出日志。向 [GitHub Issues](https://github.com/kingstacker/Kkindle/issues) 反馈时，附上 Kkindle 版本、操作系统、问题步骤和预期结果。不要公开 API Key、账号密码或未授权的书籍文件。
