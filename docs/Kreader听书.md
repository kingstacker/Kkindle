# Kreader 听书

Kreader 的“听书”入口位于 EPUB 阅读器顶栏。Windows、Linux 和 macOS 桌面版统一使用微软 Edge 的免费在线语音（`edge-tts`），无需购买密钥：

- **edge-tts**：联网调用微软 Edge 的在线语音合成，默认提供晓晓、晓伊、云希、云健等中文音色，以及英文和多语音色。
- 首次启动的引导页会询问是否自动安装听书组件，和 Calibre 的安装选项放在一起；选择“暂不安装”也不会影响手动启用。
- 第一次打开听书时，Kkindle 会自动安装到自己的数据目录：Windows/Linux 使用 pipx 专用环境；macOS 使用应用专属的 Python 虚拟环境，并在应用内用系统自带的 AVFoundation 播放音频。
- 自动安装失败时，设置面板会显示对应平台的安装提示；语音合成与试听都需要联网。

朗读按正文自然边界分段，当前片段会在 Kreader 中高亮；勾选“自动朗读下一章”后，章节结束会继续播放下一章。手动翻章、关闭阅读器或返回书架会停止播放。
