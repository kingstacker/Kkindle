# 扩展 S3 同步内容

同步协议当前为版本 5。版本 5 开始携带已删除书籍的批注展示资料（书名、封面和更新时间）。旧客户端不能安全维护这些封面引用，遇到更新版本的快照必须在上传和清理之前中止；各设备应一起升级。

新增同步实体时：

1. 在 `S3SyncSnapshotModels.cs` 声明可移植的快照类型和集合。本机路径、凭据等不能序列化。
2. 在 `S3SyncService.EntityRegistry.cs` 注册集合、稳定主键、版本、删除覆盖规则及对象哈希。注册表统一用于版本索引、删除推断、未修改行识别、旧快照清理保护和对象引用收集。集合覆盖测试会检查漏注册。
3. 为实体实现事务内完整和增量捕获，并在合并事务中实现领域规则。身份映射、阅读数据重置代次、外键依赖等仍需要明确处理，不能只注册集合就开始同步。
4. 如果需要外部对象，在事务外校验并下载，在数据库事务内保存引用。对象缺失或损坏时不要推进对应资料的版本，以便下次重试。上传也必须在快照上传之前完成。
5. 明确删除策略。批注仅由自身删除记录覆盖；书籍删除不能代替批注删除。随批注派生的展示资料不通过集合缺失推断删除，避免仅删除书籍便丢失封面。
6. 增加双向、多设备、离线旧版本、重复同步、删除与保留、对象故障和清理测试。变更会影响旧客户端合并或清理安全时，提高协议版本，并验证拒绝新版快照期间远端无写入或删除。

展示资料按 `UpdatedAt` 合并；相同版本依次按书名和封面内容哈希的序数排序确定结果。时间比较保留完整精度。资料、批注和删除记录在同一 SQLite 事务中捕获，封面哈希和网络操作在事务外处理。
