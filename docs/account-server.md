# Kkindle 分区账号与同步服务

桌面端左侧的“登录 / 注册”和移动端“我的 → 登录 / 注册”支持选择**中国区 / 国际区**。
每个区域分别记住服务地址和登录会话。两区的账号数据库、会话和同步文件独立；相同用户名
可以在两区分别注册，另一地区的令牌无法登录或读取文件。

注册成功后直接登录。用户名为 3–32 位字母、数字、点、下划线或连字符，不区分大小写；
注册必须填写邮箱、用户名、登录密码及确认登录密码，两次密码必须一致；之后可以使用用户名
或邮箱登录同一个账号。用户名和邮箱在各自区域内不区分大小写且唯一；已有账号可以保留
原来的空邮箱，继续使用用户名登录。密码为 8–128 位，区分大小写。
登录后可用注册邮箱接收 8 位验证码完成邮箱验证；忘记密码时可向注册邮箱发送验证码重置密码。
验证码 15 分钟内有效、最多尝试 5 次，同一账号 1 小时内最多发送 3 封且 60 秒内不重发。
重置密码会撤销该账号的全部会话和设备登录，需使用新密码重新登录。未配置邮件服务时，
邮箱验证和密码找回提示邮件服务暂不可用；暂不提供第三方登录。

独立正式服务默认限制同一 IPv4 地址在滚动 24 小时注册 3 个账号、30 天 10 个账号，
IPv6 按 `/64` 网段合并计数。来源记录持久化，注销、删除或重启不释放名额；并发注册在数据库锁内检查，
只统计成功注册，30 天后定期清理。超限返回 `429 registration_limit_reached`。
来源只取连接及明确可信代理；生产未配置可信代理时不采纳任何转发头。

后台 `/admin/registration` 支持 IP / CIDR 网段、邮箱、用户名黑名单及到期、查询、解除。
管理员封禁自动限制该邮箱和用户名再次注册，删除账号后仍保留限制；受限用户名也不能通过修改取得。
解封只解除该账号封禁产生的规则，手动规则须单独解除。IP 黑名单仅限制新注册，不阻止正常用户登录。
用户名或注册信息受限时客户端显示明确提示。邮箱在注册时验证格式和唯一性，登录后可通过验证码验证所有权；生产仍建议配合机器人验证。

账户中心的“账号资料与安全”支持修改用户名及密码，操作前需要输入当前密码。注册邮箱
只读，不支持修改或清空；邮箱旁显示验证状态，可发送验证码完成验证。服务端先检测重复用户名，并以数据库唯一约束防止并发重名；改名保留原账号、会员、
设备和云数据。修改密码后轮换本机登录会话、撤销其他设备会话，本机继续登录。

注销账号需要在独立确认窗口输入当前密码和完整的“注销账号”，再点击“确认注销”。
服务端立即撤销全部会话并阻断同步，将账号和云同步数据的删除加入持久化任务，失败自动重试。
客户端显示申请已提交，清理完成后服务端才记录完成；本地书库保留。

Free 仅保留本地和 USB 功能，不提供多端同步。功能解锁用户使用自备 S3 / WebDAV，
自行承担存储与流量费用；Kkindle 云同步、空间和下载额度只提供给有效 Plus，不再提供 100 MB 免费空间。

会员绑定账号，支持登录后兑换永久功能会员或 **1 年期 Plus** 激活码。接口中的档位值仍为 `free` / `lifetime` / `pro`，商品为 `lifetime`、
`plus-365d`。Plus 不附赠功能解锁：到期后撤销全部 Kkindle 云同步与下载，以及自备 S3 / WebDAV
（已购功能解锁的自备存储权益保留）。Plus 的 50 GB 下载额度按每个购买周期发放，续费额度
从新周期开始可用，未用完到期作废。不限制月流量：上传只统计用量，下载可以在一个月用完全年额度。
空间、单文件大小和并发上传限制照常检查；跨月或提前续费不会补回本年度已用额度。

账户中心嵌入桌面主窗口右侧功能区，由左侧账户入口或云同步设置中的账户入口切换到此页，保持导航可用。
页面复用功能区的字体、标题、细分隔线与黑白按钮；账户摘要内提供退出登录，额度和设备紧凑展示，会员方案与折叠的账户安全表单放在下方，不占用固定底栏。
离开账户页清空密码和激活码输入；注销账号仍要求独立确认文字和密码。
功能解锁、Plus 及扩容服务均不支持退款，包括预付未来年度和未使用余额。账户中心在购买方案前展示此规则。
Plus 被管理员撤销后重新开通继续使用原会员年度的额度和已下载记录，不重发已经覆盖的时段。
后台“退款停用”与普通撤销分开记录：会员来源为 `refund`，审计动作为 `membership.refunded`，
不立即删除云数据，数据仍按停用后一个 UTC 自然月的保留规则处理；真实退款仍由支付渠道完成。
云空间占用始终按已发布对象统计，付款不清零；删除或覆盖后的旧对象在签名链接过期后才物理删除，
期间上传检查允许最多约两倍的瞬时重叠，防止反复覆盖放大物理存储。
一次授予多年的 Plus 也按最多 365 天的额度期逐年生效，未来额度不能提前消耗。
旧多年合并额度迁移时保留总额度及已用总量，把超出首期的已用量分配到后续期。

账户页的流量圆环展示当前 Plus 会员周期内已扣除的下载用量与本期额度的比例。接口提供
`plusDownloadQuotaBytes`、`plusDownloadUsedBytes`、`plusDownloadStartsAt` 和 `plusDownloadExpiresAt`，
与月度流量计数分开。后台已移除月度重置入口，当前月份统计包括旧历史批次。
管理员调整直接修改本期下载总额，保留额度 ID 和已用量，圆环也显示调整后的总额；未来年度不提前发放。
恢复默认使用该期原始总额，保留用量。卡片保留本月下载，不显示本月上传；旧版额外余额单独显示。
兼容字段 `uploadQuota=0` 表示不设月上传限额。

Plus 首次开通后的临时下载限额由 `plusEarlyDownloadQuotaBytes`、`plusEarlyDownloadUsedBytes` 和
`plusEarlyDownloadEndsAt` 表示；窗口结束后这三个字段为空或零，客户端不再显示。旧版本已开通 Plus
的账号升级时视为窗口已结束。快照、对象列表和连接探测使用每日独立元数据额度，接口通过
`metadataDownloadQuotaBytes`、`metadataDownloadUsedBytes` 和 `metadataDownloadResetsAt` 返回，
不占用书籍年度下载额度；超出时返回 `429 metadata_traffic_exceeded`，书籍下载仍可继续。
新用户限额超出时返回 `429 new_user_traffic_exceeded`，年度额度耗尽返回 `429 traffic_quota_exceeded`，
下载授权频率过高返回 `429 download_rate_limited`。
Plus 登录成功或首次通过激活码开通 Plus 后，桌面端自动选择 Kkindle 云同步；若用户已在同步设置中保存
S3 / WebDAV，登录 Plus 不会覆盖该选择。手机端打开“云同步”时同样默认显示 Kkindle 云同步，用户保存过
自备同步方式后则直接打开对应界面。尚未设置同步密钥时保留所选方式并暂停同步，设置密钥后可以启用。

Plus 最多可持有从当前时刻起 5 个 UTC 自然年的有效期。年费商品和 Plus 激活码每次增加 365 天；
不发行 2–5 年激活码。已有有效期、付费充值、激活码与后台赠送统一计算，待支付 Plus 订单预留容量，
取消或超时后释放。超限返回 `409 membership_limit`，不能支付到账或兑换，不会部分使用激活码。
已有历史超限会员保留原期限，但不能继续延长。会员响应的 `plusRenewalLimitAt` 和 `pendingPlusDays`
帮助客户端关闭不可续费的按钮，最终校验由服务端在账户锁内完成。

从未开通过 Plus 的账号可以领取一次 **7 天免费试用**，必须由用户在账号中心主动打开领取开关才会调用
`POST /api/accounts/trial`；重复或并发请求返回当前试用状态而不会再次发放，曾拥有 Plus 且未领取过试用的账号返回
`409 trial_unavailable`。试用期按 Plus（`pro`）处理，可立即使用 Kkindle 云同步，空间为 100 MB，
下载为 200 MB 累计额度（一期额度，不按年折算）；试用到期后下载、云同步及自备 S3 / WebDAV 停用，
云端数据保留 7 天后由持久化任务销毁。领取试用会记录首次 Plus 激活时间，试用期间或之后购买正式 Plus
从试用到期时间起顺延，并按正式配额发放新的年度下载额度。会员响应的 `trialAvailable`、
`trialClaimed`、`trialClaimedAt` 和 `trialExpiresAt` 用于展示领取开关和试用状态。

账户中心登录后的“激活码兑换”支持粘贴激活码，权益只绑定当前已登录账户，不能通过请求指定其他账户。
兑换成功后立即刷新会员及设备信息；换区、退出或关闭页面会清空激活码。网络中断后重试保留请求 UUID，
同账户同请求返回原兑换标识和当前会员状态，`alreadyRedeemed=true` 时不再次发放；权益撤销或到期后重试也不会恢复会员。
一次性激活码分区发行，跨区拒绝，已使用、停用或超过兑换截止时间的码不能使用。

独立服务后台 `/admin/activation-codes` 支持永久功能会员与 1 年 Plus 的批量发行、类型 / 状态筛选、
按会员年限 / 发行时间 / 激活时间 / 使用账户排序、停用 / 启用、单码查看及批次 CSV 导出。
列表隐藏完整激活码，查看和导出需认证、CSRF 及操作原因。用户详情的“会员激活与充值记录”展示
使用的激活码 / 订单、充值年限、激活 / 到账时间、金额与前后有效期；用户列表也可按 Plus 到期时间排序。
激活码用 160 位随机数生成，摘要用于兑换，完整内容按区域密钥加密保存，审计不写入完整激活码。
账号注销后保留随机账户 ID、已兑换状态与会员账本，不能把码恢复为未使用。

没有有效 Plus 时，服务端对 Kkindle 云同步的列表、快照、书籍、封面及下载授权返回 `402 plus_required`，
客户端停止整个 Kkindle 云同步。为节省下载额度，客户端
缓存其他设备的快照（按对象修改时间），本机快照内容没有变化时 30 天内不重复上传。

Plus 到期后，客户端显示到期提示，云端书籍、批注、书签和其他同步数据从到期时刻起保留一个
**UTC 自然月**（例如 1 月 31 日到期，保留至 2 月末同一时刻），期间禁止 Kkindle 云同步和下载。
试用 Plus 到期后只保留 **7 天**，随后销毁；试用期间或之后购买正式 Plus 的账号按正式会员的一个月规则处理。
客户端在到期前 30、7、1 天各提醒一次；同一次到期不会重复提醒，续费后按新的到期时间重新计算。
保留期内续费可恢复访问。保留期结束后，服务端后台以持久化任务自动销毁该账号的全部云端同步文件
和对象索引；失败自动重试，删除前在账号锁内复查会员是否续费，任务在重启后继续。账号及本地书库保留。
下载签名链接的有效期不超过会员到期时间，已签发的本地下载链接也会实时验证会员。

保留期限已过而清理任务尚未执行时，重新付费先安排持久化清理，旧文件销毁后再确认新订单，
不能通过晚到付款恢复超过保留期限的云数据。本地上传和下载链接只能使用一次，且验证发放链接的
设备会话；踢出、退出和改密码会使旧链接失效。上传授权在签发时计入用量统计，取消、放弃或验证
失败仍保留统计，上传完成不重复计数。签名生成失败时事务回滚。
S3 完成上传后，服务端把校验通过的对象复制到独立的不可变发布键再索引；上传链接在有效期内
重放只能改写临时对象，不能替换已发布内容。每个账号每分钟最多申请 240 次上传授权。

S3 预签名下载链接本身可重放，当前服务端记录的是授权字节，不能据此保证实际出站流量没有超限。
每次授权写入 `download_events`，只保存对象键的 SHA-256、对象类型、范围、授权 / 实际字节、
状态和来源网段，不保存对象键或完整链接。本地存储链接会回写实际写出字节；S3 直连仍按授权字节
扣减，正式部署需用存储商日志对账实际出网。每账号每分钟最多申请 120 次下载授权，后台可查看
最近下载事件并调整新用户限额或豁免单个账号。
上传完成后发布独立副本，重放上传链接不能替换已发布内容；但下载链接仍可在有效期内重复使用或分享。
正式 S3 部署仍需要存储端 / CDN 的一次性或实际计量与限额，以及会员撤销 / 踢出后的链接撤销配套。
上线前必须用真实存储验证签名 `Range` / `Content-Length` 被强制校验，FakeS3 测试不能替代。

所有账号最多同时登录 **6 台设备**。账号页显示本账户已登录设备、当前设备、最近访问，
可踢出设备以释放名额；被踢设备的服务端会话立即失效。管理员还能停用设备，阻止重新登录。
客户端后台每 **24 小时**检查一次，成功时间跨重启保留；网络失败保留登录并重试，失效后
清除对应区域会话并提示重新登录。登录、手动刷新和自定义功能使用仍实时验证权限。
设备身份为平台密钥库保护的随机 ID，不使用硬件序列号；身份、会话、检查时间和会员状态
不进入备份或云同步，导入备份不会占用原设备身份。

账号页可创建功能解锁和 Plus 订单并取消待支付订单。额外空间包和下载流量包已下架，此前到账的
空间包保留至到期，旧下载余额保留，但使用 Kkindle 云同步仍需有效 Plus。空间不足或下载额度用完时
保留已有加密文件，可先清理云端数据；已删除对象的空间在签名链接过期后完全释放，短时间内容量
检查可能仍按最多两倍额度计算。会员过期则按上述一个月保留规则处理。

**目前只接入管理员确认到账，真实支付网关未接入。** 本机演示不收真实款项；生产购买默认
关闭，价格仅是服务端示例配置。客户端不能指定价格或自行发放权益，管理员核实付款后
在 `/admin/orders` 确认，订单创建和到账均幂等，待支付有效期为 48 小时。

后台用户详情支持“撤销会员权益”，可选择功能解锁、Plus 全部剩余有效期或两项会员权益，需勾选确认并填写原因。
同类待支付订单取消；保留已到账订单、激活码与历史消耗记录。单独撤销 Plus 保留另购的功能解锁；
单独撤销功能解锁时，有效 Plus 的同步权限保留。撤销 Plus 从撤销时刻开始一个 UTC 自然月的云数据保留期，
旧本地签名链接和未完成上传失效；重新购买不恢复这些旧授权，也不重置已用量。后台撤销不产生资金退款。

本机保留 8 个中国区 `demo_cn_` 虚构账号，运行独立服务器的 `python3 scripts/seed-demo.py`
即可准备。密码只在该项目 `.local/demo-users.json`（0600）中，国际区不创建这些演示账号。

## 独立服务器项目与本机验证

用户管理服务位于桌面的独立项目 `~/Desktop/Kkindle_server`，使用 ASP.NET Core / .NET 10、
PostgreSQL 和中文管理网页，不依赖客户端源码路径。操作与部署资料在该项目的 README 中。

```sh
cd ~/Desktop/Kkindle_server
python3 scripts/local.py start
python3 scripts/local.py test
```

本地脚本使用专属的回环 PostgreSQL 集群，为两区分别创建数据库、数据库账号、文件目录与
管理员会话。初始管理员为 `local-admin`，两区的不同随机密码在被忽略且仅本机用户可读的
`.local/local-config.json` 中；不会写进源码或打印到日志。

| 区域 | 客户端服务地址 | 管理网页 | 账号数据库 | 加密文件 |
| --- | --- | --- | --- | --- |
| 中国区 | `http://127.0.0.1:5088` | `http://127.0.0.1:5088/admin` | PostgreSQL `kkindle_china` | `.local/storage/china/sync/<account-id>/` |
| 国际区 | `http://127.0.0.1:5089` | `http://127.0.0.1:5089/admin` | PostgreSQL `kkindle_international` | `.local/storage/international/sync/<account-id>/` |

PostgreSQL 只保存账号、会话哈希、封禁、额度、流量、存储汇总和管理记录。书籍与同步快照
由客户端加密后存入独立文件目录；数据库没有书名、书籍清单、正文或解密密钥。管理网页
支持封禁/解封、撤销会话、调整云空间及本会员年度下载总额和删除任务，不提供查看或下载书籍的入口。
用户列表支持搜索用户名、邮箱或账号 ID，筛选状态和会员类型；可按用户名、邮箱、会员、
上传/下载、年度下载已用、累计流量、存储、设备数、注册时间和最近登录升降序排列。
删除须先封禁，之后可选择只删除云数据或同时删除账号。删除账号后同名用户可以重新注册；
需要保持拉黑状态时，选择只删除云数据。离线备份按服务器的独立保留计划清理。

`GET /health` 返回服务标识 `kkindle-accounts`、区域（China 为 0，International 为 1）和
`administration: true`。数据库和文件目录首次初始化时记录所属区域，禁止跨区复用。

macOS 桌面端、移动端预览和 iOS 模拟器直接使用 `127.0.0.1`；Android 模拟器的开发机
地址为 `10.0.2.2`，端口仍分别为 5088 / 5089。真机连接可访问的 HTTPS 服务。

在登录页选择区域、切换到注册、填写邮箱、用户名、登录密码和确认登录密码。再到同步设置选择
“Kkindle 云同步”，设置并保存同步密钥，再点击测试连接或立即同步。账号同步复用现有书库快照合并协议，包含书籍、
批注、书签和阅读记录；书籍文件默认按需下载，也可开启同步时下载。

同步密钥只在用户设备本地保存，不上传服务器，不导出到备份。用户须自行牢记；遗忘后
无法解密已有云数据或 `.kkindle` 加密备份，服务器没有密钥找回能力。完整数据备份的
导入和导出也必须使用已配置的密钥，详见[加密备份说明](backup-encryption.md)。

新上传的加密书籍与封面统一使用 `objects/encrypted/<64位命名空间>/<64位不透明名字>`。
最后一段是由同步密钥派生的命名密钥对文件 SHA-256 计算的 HMAC，不是明文文件哈希；
路径也不包含口令或可快速验证口令的密钥摘要。命名密钥使用 PBKDF2-SHA256（12 万次）
及独立用途标签派生，只在一次同步／下载的内存会话中存在。账号云同步按区域和账号 ID
隔离，服务器域名不参与命名，后期迁移域名不会改变对象名字。

自备加密 S3 / WebDAV 使用随机命名盐，保存在**加密快照**的 `BlobNamingSalts` 中，
不额外上传公开口令摘要或盐配置文件。多设备首次同步产生不同盐时合并保留所有命名空间，
后续采用同一排序规则，读取、去重及清理兼顾全部保留盐，不会因为初始化竞争丢失文件。
未设置密钥的自备存储仍是明文 `objects/plain/<SHA-256>`，不承诺隐藏文件指纹。

新加密书籍与封面使用 `KKINDLE-SYNC3`：真实长度放在认证密文内，数据按 Padmé 规则
分档向上补齐；公开分块长度只反映补齐后的大小。服务器仍能看到对象数、大致大小、传输
时间及同步频率，不能宣称消除了全部元数据泄露。快照仍使用 `KKINDLE-SYNC1`。

同步快照和最低读取协议提高为 **6**，所有设备须一起升级。新客户端继续读取旧版快照及
`SYNC1`／`SYNC2` 对象；旧路径仅从不含口令摘要或文件哈希的目录列表中发现，不猜测
旧哈希路径、不向旧目录写入，也不自动删除旧对象。已有开发版账号云对象同样可只读发现，
无需清空现有演示数据。旧名称暴露过的哈希不会因此消失；更新设备、确认新文件与备份
可解密后，再由用户自行清理原目录。更换密钥仍须使用新的同步前缀。

## 客户端区域隔离

中国区沿用已有安装根目录下的书库；国际区使用 `<安装根目录>/regions/international/`。
数据库、阅读记录、同步配置、设备 ID、同步基线和备份目录分别保存。切换区域后可以立即
注册、登录或退出该区域账号；界面提示重新打开应用，以加载对应区域的独立书库。
重新打开前，当前进程禁止同步和按需下载，包括后台同步，避免向另一地区发送现有书库。
切回原区域并重新打开后，原来的本地书库和登录状态仍保留。

“Kkindle 云同步”绑定当前登录的区域、服务地址和用户 ID；服务端仅从认证会话确定文件所有者。
更换账号、服务地址、退出或会话失效时，旧的同步配置不能继续使用。Plus 登录成功后自动选择
当前账号的 Kkindle 云同步，保留原同步启用状态；若缺少同步密钥，则暂停传输，待配置密钥后启用。
正在进行的同步完成后再保存新的选择。之后手动保存 S3 / WebDAV，刷新或重新打开账户中心不会覆盖选择；
再次登录 Plus 也不会覆盖，下次打开“云同步”会直接显示保存的方式。

应用中的 S3 / WebDAV 同样使用区域命名空间：`regions/china/<目录前缀>/` 和
`regions/international/<目录前缀>/`。即使填写相同 Bucket 或 WebDAV 地址，两个区域也不会
合并数据。已有未分区的远端 `<目录前缀>/` 数据不会自动迁入，新版首次同步使用分区目录；
原有本地书库会上传到当前区域。每个区域独立保存连接凭据。连接参数文件仍只支持 S3 / WebDAV；
账号会话不能导出。普通备份不包含账号会话，恢复备份不会自动启用 Kkindle 云同步。

## 服务器配置

独立服务器需要 .NET 10 ASP.NET Core Runtime 和 PostgreSQL。正式环境将两区服务运行在各自区域的主机上，
使用独立的数据卷、备份和 HTTPS 域名。网关按域名固定代理对应区域，不配置跨区回退、
账号复制或同步数据复制。客户端两区默认地址集中在
`src/Kkindle.Core/AccountServerEndpoints.cs`，支持 `KKINDLE_ACCOUNT_SERVER_CHINA` /
`KKINDLE_ACCOUNT_SERVER_INTERNATIONAL` 环境变量覆盖；已登录令牌仍绑定原服务器。
完整字段、已安装客户端的默认地址更新和部署注意事项见[部署配置入口](account-server-deployment.md)。

### 对象存储与签名直传

Kkindle 云同步在 `S3` 模式下的加密字节不经过账号服务；`Local` 模式由服务自身提供
签名传输端点。服务端负责授权、计费和索引，客户端拿到短期签名链接后与对应存储传输，
链接本身不携带账号会话：

1. 上传：`POST /api/sync/uploads` 声明路径和长度，服务端检查账号状态、空间和流量（书籍文件另需 Plus）后预留额度并签发
上传链接（签入 `Content-Length`，有效期不超过 Plus 到期时间）。客户端 `PUT` 到链接后调用 `complete`，服务端核对实际长度与
   加密头再计费、发布；失败时客户端取消预留。
2. 下载：`POST /api/sync/downloads`，服务端先按范围扣流量再签发链接（签入 `Range`）。
3. 存储后端由服务端 `Storage__Provider` 决定：`S3` 使用七牛 Kodo 等 S3 兼容私有空间，对象名只是随机
   ID；`Local` 保存在服务器目录，由服务自己提供 `/sync-blobs/` 链接，供开发和小规模部署。

客户端只接受 HTTPS 链接（回环开发地址除外），且不对链接发送会话或跟随重定向。用户自己配置的
**自定义 S3 / WebDAV 同步**仍直连用户自己的存储，不经过也不依赖账号服务器。

代理须转发 `/api/accounts/`、`/api/sync/`、`/sync-blobs/` 和 `/health`。Nginx 示例（中国区服务）：

```nginx
location / {
    # 仅 Local 存储模式需要 512m；S3 模式下书籍直传对象存储，可调小。
    client_max_body_size 512m;
    proxy_pass http://127.0.0.1:5088;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

将此段放入已配置 TLS 的 `server` 中；国际区代理到其独立服务。代理在其他主机上时，用
`Server__KnownProxies__0` 指定实际可信代理 IP，并使用 `ConnectionStrings__Accounts` 环境变量
提供此区域的 PostgreSQL 连接信息。运行进程使用专用用户，数据目录仅允许
该用户读写。服务拒绝远端明文 HTTP；客户端仅允许回环地址及 Android 开发机别名使用 HTTP。
登录和同步均拒绝 HTTP 重定向，账号同步始终校验 TLS。

## API 与会话

所有账号和同步请求必须携带 `X-Kkindle-Region: china` 或 `international`，并与服务的固定
区域相同，否则返回 403。认证 JSON 中的 `region` 同样必须匹配。区域标签由服务器配置
决定；请求头用于防止误连，不能改变服务器区域。

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| POST | `/api/accounts/register` | JSON 必填 `email`、`username`、`password`、`confirmPassword`，以及 `region`、`deviceId`、`deviceName`、`platform`；校验邮箱格式、用户名与邮箱唯一性和两次密码一致后创建账号并返回会话 |
| POST | `/api/accounts/login` | JSON `username` 可填写用户名或邮箱，还需 `password`、`region`、`deviceId`、`deviceName`、`platform`；验证后返回会话 |
| GET | `/api/accounts/session` | `Authorization: Bearer <SESSION_TOKEN>`；验证设备会话、更新最近访问，不延长到期时间 |
| POST | `/api/accounts/logout` | 同一认证头；撤销当前会话，返回 204 |
| POST | `/api/accounts/password-reset/request` | 匿名；JSON `username`（用户名或注册邮箱）；已知账号且邮件服务可用时发送 8 位验证码，未知账号同样返回 202 但不发信 |
| POST | `/api/accounts/password-reset/confirm` | 匿名；JSON `username`、`code`、`newPassword`、`confirmPassword`；成功后撤销全部会话并标记邮箱已验证，返回 `user` |
| POST | `/api/accounts/email/verify/request` | 认证头；向注册邮箱发送 8 位验证码；未设置邮箱返回 `409 email_not_set` |
| POST | `/api/accounts/email/verify` | 认证头；JSON `code`；成功后返回 `user`（含 `emailVerified: true`） |
| GET | `/api/sync/objects?prefix=<PREFIX>` | 列出当前账号的对象键和修改时间 |
| HEAD | `/api/sync/objects/<KEY>` | 返回当前账号对象的长度和修改时间 |
| DELETE | `/api/sync/objects/<KEY>` | 删除当前账号的对象；旧数据在已签发链接过期后清理 |
| POST | `/api/sync/uploads` | JSON `key`、`length`；预留空间并按授权长度计入上传防滥用用量，返回 `uploadId`、`url`（签入长度）、`expiresAt` |
| POST | `/api/sync/uploads/<ID>/complete` | 核对已上传对象的长度与加密封装后发布，不重复计费，原子替换同名对象 |
| DELETE | `/api/sync/uploads/<ID>` | 取消空间预留，已签发授权的上传计数不退回；未完成的预留 6 小时后自动失效 |
| POST | `/api/sync/downloads` | JSON `key`、`offset`、可选 `length`；先扣流量，返回 `url`、需原样发送的 `range`、长度与总长度 |
| GET / PUT | 签名链接 | 不带会话；上传必须声明与授权一致的 `Content-Length`，最多 512 MiB |
| GET | `/api/accounts/membership` | 当前账号会员、额度、余额与设备数量 |
| GET | `/api/accounts/devices` | 当前账号设备列表 |
| GET | `/api/accounts/devices/<DEVICE_ID>` | 验证当前会话绑定的设备，返回会员与设备状态 |
| POST | `/api/accounts/devices/<DEVICE_ID>/features` | 验证当前设备的功能权益 |
| POST | `/api/accounts/devices/<DEVICE_ID>/kick` | 踢出本账户的设备，立即撤销其会话 |
| GET | `/api/accounts/products` | 当前服务端商品；购买关闭时为空 |
| GET / POST | `/api/accounts/orders` | 列出订单，或用 `productId`、`requestId` 创建待支付订单 |
| POST | `/api/accounts/orders/<ORDER_ID>/cancel` | 取消自己的待支付订单 |
| POST | `/api/accounts/activation-codes/redeem` | 必须登录；JSON `code`、非空 UUID `requestId`，返回 `codeId`、`kind`、`years`、`redeemedAt`、`status`（当前会员 / 设备）和 `alreadyRedeemed`；Plus 只发放 1 年 |

注册/登录返回 `region`、`user: { id, username, email, emailVerified }`、`token`、`expiresAt`，旧账号的 `email` 可为空。
错误密码和不存在的账号统一返回 401；重复注册返回 409；同一来源每分钟最多 10 次
注册/登录，超过后返回 429。认证请求体最多 16 KiB。

独立服务另有持久化成功注册数量限制；注册超限返回 `429 registration_limit_reached`，
命中黑名单返回 `403 registration_blocked`，改为受限用户名返回 `403 username_blocked`。
过保留期的云数据需先清理时，到账返回 `409 cloud_retention_due`，订单继续保留待确认。

第七台设备返回 `409 device_limit_reached`；被管理员停用的设备无法登录。自定义功能无权益时
返回 `402 membership_required`。服务端 v1 → v2 迁移会撤销缺少设备标识的旧普通会话，需要
更新客户端并重新登录；旧书库和加密数据保留，管理员会话保留。本机测试限速放宽至每分钟
1,000 次，正式默认仍为 10 次。

密码使用随机盐和 PBKDF2-SHA256（600,000 次迭代），数据库不保存原始密码。会话使用
32 字节随机令牌，有效期 30 天；服务器只保存令牌的 SHA-256 哈希。账号和会话在服务重启
后保留。退出仅撤销当前设备、当前区域的会话，不影响其他设备或另一地区账号。
客户端通过平台 `ISecretProtector` 独立加密两区会话，不保存账号密码；会话不进入任何云同步
或 `.kkindle` 备份。服务器不可用时仍可在本机退出，界面提示远端撤销尚未完成。

## 阅读周期

阅读数据按钮为“周 / 月 / 年”，默认选中周。本周从周一开始；本月按实际天数显示；
今年按 12 个月汇总，包含闰年的 2 月 29 日。未来日期显示为空，不计入时长。统计沿用现有
阅读记录的 UTC 日期；切换周期不改变累计时长、近七天日均、最近阅读和勋章数据。
