# Kkindle 主界面优化施工文档

版本：1.0 · 编写日期：2026-09-09 · 面向执行改造的 AI / 开发者

**本次交付是施工说明，不包含代码实现。** 后续执行者根据本文修改现有 Avalonia 桌面应用。目标是将主界面调整为参考图中的轻盈书库风格，同时保留现有业务能力。

## 1. 任务依据与执行边界

用户需求：根据提供的 UI 图片优化当前软件主界面，提供可交给其他 AI 的施工文档。

配套文件：本目录 `reference.png`，为用户原图的原样副本。转交时请把本文和图片放在一起；执行者还需要访问 Kkindle 源码仓库。

![用户提供的主界面参考图](reference.png)

证据与决策分开理解：

- **已核实的现状**：来自当前工作区源代码；本文所列控件、方法和参数均按本次检查记录，执行时应重新核对。
- **图片表达的方向**：白色界面、较宽侧栏、清晰导航、淡蓝选中态、柔和书籍卡片、胶囊搜索框、较低的信息噪声。
- **本文确定的设计方案**：具体色值、尺寸、自适应规则和图片未展示的状态，是为可施工而制定的建议值，并非对图片的精确取色或逐像素测量。
- 图片中的书名、69 本数量、Kindle 品牌文字和头像均为参考内容，不是必须写入软件的数据，也不是新增账户功能的指令。
- 未运行应用核验当前实际画面。本次检查过仓库内历史截图，但其与当前源代码存在差异；后续必须用本次构建的真实界面作为验收依据。

范围：主窗口外壳、侧栏、电脑书库页头、搜索与工具栏、网格/列表/收藏夹入口、卡片、设备状态、空态和选中态。侧栏共用页面需做兼容验证；Kindle 书库可复用卡片风格，但其设备业务保持现状。

不在范围内：阅读器排版、听书、AI 服务、同步协议、数据库结构、格式转换内核及设置页内容重构。不要重写成网页，不换技术栈，不新增登录系统，不拿参考图替代真实书库。

仓库 `AI_HANDOFF.md` 中有旧的“黑白灰、直角细线”约定。本次主界面采用用户新参考图中的圆角、柔和阴影与淡蓝选中态；该变化限定于主界面，不能借此批量改动阅读器样式。其他数据、平台和安全约束继续适用。

## 3. 总体视觉目标

按视觉优先级施工：①窗口和侧栏比例；②页头与工具栏层级；③封面卡片节奏；④字体与颜色；⑤阴影与微交互。

期望第一眼看到的是“书库与书”，而不是密集的黑色线框。主界面保留产品名 **Kkindle**，副标“个人电子书架”，不要照图改名为 Kindle。

### 3.1 设计变量

尺寸单位为 Avalonia DIP。原图是像素图，不能将高 DPI 下的物理像素直接当作 DIP。

| 变量 | 建议值 | 用途 |
| --- | --- | --- |
| 主内容背景 | `#F7F8FA` | 提供轻微层次，保持近白观感 |
| 侧栏 / 卡片背景 | `#FFFFFF` | 干净、可辨认的表面 |
| 主文字 | `#172033` | 标题、书名、主要操作 |
| 次文字 | `#667085` | 作者、辅助说明 |
| 弱文字 | `#7A8496` | 数量、占位、次级提示；实际组合需核对可读性 |
| 细边线 | `#E6E9EF` | 分隔线、输入框边缘 |
| 导航选中背景 / 文字 | `#E8EDFC` / `#263F73` | 淡蓝底与深蓝字，不用整块深色底 |
| 悬停背景 | `#F0F3F8` | 导航与工具按钮 |
| 搜索框背景 | `#F1F3F6` | 与卡片白色区分 |
| 卡片 / 导航圆角 | 8 / 10 | 轻微圆润 |
| 搜索框 / 弹出层圆角 | 22 / 10 | 搜索框高 44 |
| 卡片阴影 | 黑色约 6%–8%，向下 3，模糊约 12 | 低强度，不形成厚重投影 |
| 布局间距 | 4、8、12、16、20、24、32 | 统一间距序列 |

颜色在主界面专用资源内维护。不要直接替换全局 `InkBrush`、`PaperBrush` 或 `DefaultAppFontFamily`，以免阅读器及其他弹窗被连带修改。也要检查控件局部值是否覆盖新样式。

### 3.2 字体

- 主界面采用易读无衬线字体；Windows 优先系统中文 UI 字体，macOS/Linux 使用平台可用的中文无衬线回退。避免强依赖某台电脑独有的字体。
- 品牌 24 / SemiBold；页标题 28–30 / SemiBold；副标题 15 / Regular；导航 16 / Medium；工具栏 14；书名 15 / SemiBold；作者 13；数量 13。
- 页标题“电脑书库”可保留现有宋体作为局部强调；其他界面文字不要继续被全局宋体样式强制覆盖。阅读器字体偏好不变。
- 以真实中文、英文、长作者名和缺字情况验收，不能仅用数字占位。

## 4. 布局与自适应

主界面依次为：左侧固定导航；右侧页头、工具栏、可选筛选区域、可滚动书籍区、条件显示的分页/状态区域。

### 4.1 窗口和侧栏

- 保留当前自定义标题栏拖动、双击最大化、最小化、还原与关闭事件。最上方约 32 DIP 作为窗口操作安全区域；搜索和按钮不能成为拖动热区。
- 普通窗口可使用约 12 DIP 外轮廓圆角和轻阴影。最大化后不能留下透明边框；三端标题栏差异沿用现有平台逻辑。
- 客户区宽度 ≥1200 时，侧栏宽 276；1024–1199 时宽 220。侧栏内边距宽屏 24、窄屏 16；主内容左右边距对应 32、24。
- 品牌区使用 44×44 深色 K 标识，右侧品牌与副标；云图标独立占 32–36 的点击区域。窄屏品牌字号可降至 22。
- 导航行高 48–52，图标 20，图标与文字间隔 12。选中背景覆盖整行可点击区域；计数为右侧浅灰/浅蓝圆形或胶囊徽标。
- 书籍管理默认展开；电脑书库、Kindle书库、Z-Library 在线书库保留。设备管理和阅读资料保留折叠箭头及现有子项，设置保留原入口。
- 展开多个分组时只让导航中段滚动，品牌和底部设备状态固定。1024×664 下不能用导航项遮盖设备状态。

### 4.2 页头

- 标题行左侧显示“本地”深色小标签，再显示“电脑书库”。标签圆角 4，高约 28，标题基线视觉对齐。
- 标题下显示“记录阅读，构建更好的自己”，与标题间隔 8。它是静态副标题；不要把持续变化的任务状态写进此处。
- 右上角放“更多”入口，至少承载已有导入操作。参考图中的头像不作为首期必做项；如果没有明确对应的现有账户总览，就省略，不能创建无行为头像或伪造已登录状态。
- 新页头不能侵入右上角窗口控制按钮的点击区域。

### 4.3 工具栏职责

宽屏顺序：**搜索框 → 筛选 → 视图 → 排序 → 弹性留白 → 网格/列表切换 → 结果数量**。工具栏与页头间隔 18–20，与第一排卡片间隔 20。

| 元素 | 视觉与行为 |
| --- | --- |
| 搜索 | 高 44，宽屏目标宽 360–500；左放搜索图标、右放清除按钮。占位“搜索书名、作者或关键词…”；实际匹配范围继续采用现有搜索实现，不暗示新增全文搜索 |
| 筛选 | 漏斗图标＋“筛选”，展开现有筛选能力；有条件时显示数量小徽标 |
| 视图 | 图标＋“视图”菜单，明确列出网格、列表、收藏夹；菜单下方可提供现有画廊显示与封面灰阶偏好的快捷入口，须接到原设置 |
| 排序 | 使用明确排序图标＋“排序”，展开真实排序选项，当前项有勾选 |
| 网格/列表分段按钮 | 外框约 88×40，两个独立按钮；当前项白底轻阴影，另一项透明；直接切换，不循环 |
| 数量 | 无条件时“共 N 本书”；搜索/筛选时“找到 M 本 / 共 N 本”；按业务总数计算，不使用当前页 `Books.Count` |

“视图”负责完整模式和显示偏好，分段按钮是常用模式快捷操作，两者共享唯一状态。收藏夹概览时分段按钮隐藏；进入某个收藏夹后恢复，且切换网格/列表保留当前收藏夹范围。

当前 `ImportButton` 使用向下箭头图标，参考图“排序”也呈现向下图形。**不能把原导入按钮只改文案就变成排序。** 排序接排序逻辑；导入保留独立“导入书籍”菜单项、原拖放能力和空书库主按钮。不要改变现有文件选择和导入服务。

排序第一版仅使用已有五项：最近更新、书名升序、作者升序、最近添加、阅读进度降序。它们分别映射 `UpdatedDescending`、`TitleAscending`、`AuthorAscending`、`CreatedDescending`、`ProgressDescending`。不画没有实现的升降序开关。

### 4.4 窄窗口工具栏

- 客户区宽度 <1400 时，工具栏分为两行：第一行搜索框占满可用宽度；第二行筛选/视图/排序在左，分段切换和数量在右。
- ≥1400 时单行布局；如果英文文案或放大文本仍导致挤压，允许继续使用两行，以实际可用宽度优先。
- 工具按钮的点击区域至少 36×36；不可通过把字体压到 10–11 来塞下全部操作。
- 标题和工具栏固定，书籍区垂直滚动；筛选展开可增加头部高度，不能把整个窗口变成一条长滚动页面。

### 4.5 网格尺寸规则

目标：参考图宽度附近每排约 6 本；1294 默认窗口约 5 本；最小窗口约 4 本。宽屏允许更多列，不把卡片无限放大。

定义 W 为书籍滚动视口的实际可用宽度，已扣除侧栏、主内容左右边距和滚动条占位。列间距 20，行间距 20；卡片最小宽 160，目标约 180，上限 200。

- 列数先取 `floor((W + 20) / 180)`，至少 1 列。
- 卡宽取 `(W − (列数 − 1) × 20) / 列数`，超过 200 时限制为 200，剩余空间留在右侧，不把间隙无限拉大。
- 每行左对齐；不足一行时保持同一列宽。尺寸计算统一处理 DIP 舍入，不累计误差造成最后一列裁切。
- 下表按预留 12 DIP 滚动空间估算；实际视口尺寸优先，列数是验收参考。

| 客户区宽度 | 侧栏 | 主内容左右边距 | 估算 W | 列数 / 卡宽 |
| --- | --- | --- | --- | --- |
| 1024 | 220 | 24 / 24 | 744 | 4 / 171 |
| 1294 | 276 | 32 / 32 | 942 | 5 / 172.4 |
| 1552 | 276 | 32 / 32 | 1200 | 6 / 183.3 |
| 1920 | 276 | 32 / 32 | 1568 | 8 / 178.5 |

不要保留模板宽 154、槽宽 166、ViewModel 卡高和运行时面板尺寸各自独立的状态。要从同一套布局结果得到卡宽、卡高、槽宽、槽高，并使框选边界与最终排列一致。

## 5. 书籍卡片规范

### 5.1 结构

- 白色完整卡片，上方封面区、下方文字区，外轮廓圆角 8；默认没有明显黑色描边。
- 封面区统一高为卡宽的约 0.90 倍，文字区固定高 64；普通卡总高约为 `0.90 × 卡宽 + 64`。原图各排封面高度并不完全一致，实现时统一高度，保证书墙整齐。
- 默认保留完整封面比例，使用等比适配居中，空余部分使用中性浅底；不拉伸图像。此处是对参考图满铺观感的有意调整，优先保证真实竖版书封标题可读。
- 文字区左右内边距 12、顶部 9。书名一行省略，作者一行省略；书名行高约 21，作者行高约 18，间隔 4。悬停或键盘聚焦可查看完整信息。
- 普通网格不常驻第三行格式信息。格式、文件数等保留在列表、详情和工具提示中，数据不删除。
- 无作者显示“未知作者”；无封面/封面损坏显示书籍图标与“暂无封面”，卡片下方仍显示真实书名。不存在有效书名时才用“未命名书籍”。
- 画廊偏好开启时隐藏文字区并同步缩短卡高；关闭时恢复书名/作者。尊重已有用户偏好，不为接近参考图强行重置灰阶或画廊设置。

### 5.2 状态与事件

| 状态 | 呈现 | 交互要求 |
| --- | --- | --- |
| 默认 | 白底、轻阴影、无强描边 | 卡片整个区域可命中 |
| 悬停 | 轻微增强边线/阴影 | 不改变尺寸，不造成网格跳动 |
| 单选 | 1.5 DIP 深蓝轮廓 | 保留现有单击延迟打开详情的行为 |
| 多选 | 轮廓＋左上角勾选标记 | 保留 Ctrl/平台修饰键、Shift 范围选择、拖框和取消选择逻辑 |
| 键盘焦点 | 清楚的焦点环 | 与选中态可区分，不能移除默认焦点而无替代 |
| 转换中 | 封面右下角紧凑进度徽标 | 保留点击恢复转换弹窗的事件，不能触发打开书籍 |
| 本地/设备存在状态 | 封面角落紧凑徽标 | 继续遵循现有比较功能开关，带文字提示和无障碍名称 |

双击仍打开原书籍；右键仍打开原上下文菜单。不要在一次双击中同时展开详情和启动两次阅读器。所有装饰层不拦截输入，进度徽标等交互层除外。

设备状态徽标放右上角，转换进度放右下角，多选勾放左上角，避免互相遮挡。封面尺寸改变后重新验证触控、鼠标选择和滚动条拖动。

多选操作条复用 `MultiSelectionBar`，显示真实选中数和现有操作，条件出现；删除等业务动作沿用原确认流程。

### 5.3 列表与详情

- 列表使用白底柔和行、统一圆角及同一字体体系；保留封面、书名/作者、组织与出版信息、阅读状态和更新时间等现有数据。
- 窄屏优先保留封面、书名/作者和必要操作，次级信息允许折行或移入详情，不能制造横向滚动或挤出按钮。
- 详情继续复用 `LibraryDetailPane` 及其数据/编辑动作；本次不擅自重构为新业务弹窗。统一边线和间距，并验证窄屏关闭入口始终可达。
- 收藏夹保留新建、进入、返回、上下文菜单和现有书籍归属语义。其卡片可沿用圆角与浅边线，但不把收藏夹伪装成普通书籍。

## 6. 筛选、状态与异常

### 6.1 筛选

首期继续使用工具栏下方可收起的 `FilterPanel`，改为浅色圆角容器、内边距 16。保留作者、标签、格式、分类、阅读状态、仅收藏；宽度不足时整组换行。

排序移至专属入口后，面板内不再显示第二个排序控件。不要留下隐藏控件继续在刷新时把排序覆盖为默认值。

激活条件以简短标签概述并可单独移除；“重置筛选”仅清空筛选项，保留搜索、排序及当前收藏夹范围。“清除搜索”只清空搜索框。这是本次明确的行为改进，不能直接复用当前会清空搜索/收藏夹并重置排序的 `ClearFiltersButton_Click`。

所有筛选走原 ViewModel 查询入口，变更后回到有效的第一页或原有分页修正逻辑；不得只在当前 200 本上过滤。原搜索处理机制可先保留；只有实测出现明显重复刷新才引入短防抖，并验证中文输入法组合输入。

### 6.2 设备与同步

- 侧栏底部用细分隔线和固定状态区域：设备名称/连接标题、辅助文字、容量信息与进度条。
- 无设备时显示“无设备连接”“还未连接设备”；容量条为空或隐藏，不能用一条灰色满条暗示已经占用空间；弹出设备按钮隐藏或禁用。
- 连接中显示真实检测状态；已连接显示真实设备名、容量与可用的弹出操作；容量未知时显示“容量暂不可用”，不伪造 0 GB。
- 云图标保留已有 S3 状态和操作。失败必须能通过提示或现有面板看到原因，不能只用颜色表达，也不能点击就执行无关同步动作。

### 6.3 空态、加载与分页

| 场景 | 呈现与出口 |
| --- | --- |
| 首次无书 | “电脑书库还是空的”＋支持格式说明＋“导入书籍”主按钮，保留拖入提示 |
| 搜索无结果 | “没有找到相关书籍”＋“清除搜索”；仍有筛选时保留其可见标签 |
| 筛选无结果 | “没有符合条件的书籍”＋“重置筛选”；不误导成书库已空 |
| 收藏夹为空 | 使用现有收藏夹空态与新建入口，不显示导入能直接填充该收藏夹的错误承诺 |
| 首次加载 | 使用真实忙碌状态显示轻量进度，不短暂闪现空书库 |
| 刷新或导入中 | 尽可能保留已有书籍，底部展示任务状态/进度，不能假装操作成功 |
| 封面失败 | 单卡降级，不阻塞整页；稍后刷新可重新获取 |
| 查询失败 | 明确失败提示和可重试入口，不把异常当“0 本书” |
| 超过 200 本 | 保留分页；只有多页才显示分页条，最后一页按钮禁用正确 |

书籍总数、筛选结果数、设备数量分别来自对应真实状态。69、0 和参考书名不能作为生产硬编码。底部任务提示与顶部结果数量分开，不用同一文本字段同时承载两者。
