# 书库与阅读功能更新（2026-10-17）

本轮在 `dev` 分支完成，重点补齐跨书笔记、批量操作、重复书、智能书架、同步透明度和键盘操作。

## 跨书批注搜索与阅读笔记

- 新增“阅读笔记”窗口（书库工具栏按钮），跨书搜索划线、批注和书名。
- 支持按书籍、颜色（黑/黄/绿/蓝/粉/紫/橙）和时间范围（全部/7/30/90 天）筛选。
- 结果按更新时间倒序，显示书名、作者、章节、划线、批注和时间；双击或回车可在阅读器中打开对应位置。
- 支持导出 Markdown 和 CSV。
- 只查询 `ReaderAnnotations` 与书籍元数据，不建立全书正文索引。

## 批量操作

- 原有批量发送到 Kindle（USB/邮件）和批量删除保留。
- 新增批量编辑：标签、分类、阅读状态、收藏状态；留空保持不变，可显式清空。
- 新增批量转换：选择 EPUB 或 AZW3，已有目标格式的书籍自动跳过，逐本转换后加入书库并汇总结果。

## 重复书

- 书库工具栏新增“重复书”：按文件内容哈希（忽略大小写）查找重复书籍组。
- 合并沿用同步中的整理规则：保留每组文件最多的版本，迁移划线、批注、进度、书签、阅读统计、阅读反思和收藏夹成员；只在哈希相同的情况下合并，元数据相同但内容不同的书不会被误合并。

## 智能书架

- 筛选面板新增“智能书架”：把当前搜索词、作者、标签、格式、分类、阅读状态、收藏和排序保存为命名预设。
- 支持应用、保存和删除；预设保存在本地 `AppSettings`，不进入云端设置快照。

## 同步详情

- S3/WebDAV 设置中新增“同步详情”：显示上次同步时间、云端快照书籍/文件/批注数、已登记远端书籍、待按需下载文件、墓碑数、快照时间，以及本次同步的计数和警告。

## 阅读统计

- 阅读仪表盘新增 7/14/30 天范围选择；原有总时长、连续天数、开始/读完书籍、书签/批注、每日柱状图、按书阅读时长和进度分布保留。

## 键盘操作

- `Ctrl+F` 聚焦书库搜索，`Ctrl+I` 导入书籍，`Ctrl+A` 全选当前页。
- `Enter` 打开选中书籍，`Delete` 删除选中书籍，`Esc` 依次清除搜索、选择和筛选面板。
- `F1` 显示快捷键帮助。
- 新增按钮均带 `AutomationProperties.Name`，便于屏幕阅读器识别。
