# S3 快照兼容约定

从本版开始，快照把写入格式 `Version` 和最低读取协议 `MinimumReaderVersion` 分开。当前均为 5。旧快照没有最低版本声明时，按 `Version` 判断；支持协议 5 的客户端可读取明确声明最低版本不超过 5 的未来快照。WebDAV 共用此快照协议。

后续增加可选字段、可选实体时保持协议 5，缺失字段必须提供兼容默认行为。不能仅因为发布新软件版本而递增协议版本。字段改名、删除、更改类型、改变已有字段语义或删除规则属于破坏性修改，必须提高最低读取协议，不能伪装成兼容更新。

未知字段在快照、实体、设置、阅读布局、重置记录和删除标记上保留；同步重建及重启后的基线写回继续携带它们。实体按稳定标识匹配，只给仍存活的记录保留字段，不因未知字段恢复已删除实体。未知对象/数组整体保留，不解释其内部结构。

`ExtensionDataVersions` 保存未知字段的原始时间戳；布局字段使用 `DefaultReaderLayout/` 前缀，重置记录使用 `ReadingDataReset/` 前缀。旧客户端转发时不能把它们当作刚发生的修改。字段有意清空应写显式 JSON null，不能依靠缺失字段表达删除。未来实现某个原本未知字段时，写入新值必须同步更新对应的字段时间戳。

存在未知数据时，本客户端暂停自动远端快照淘汰、墓碑压缩和对象垃圾回收，避免删除未知字段引用的文件；已识别的业务删除仍正常同步。清理交给理解这些字段的客户端。

此能力无法追溯修改已发布的旧程序。所有设备需要先更新到本版或更高版本；之后兼容性新增不会再仅因软件版本差异阻止同步。真正破坏性升级仍需更新客户端。
